# Solo Traveller 🌍

A full-stack travel community platform built with Node.js, Express, Sequelize and MySQL.

## Overview

Solo Traveller allows users to create accounts, explore trips, create travel posts and interact with other travellers.

The project demonstrates:

- User authentication
- Session management
- Relational database design
- CRUD operations
- MVC architecture
- RESTful API development

## Features

✅ User registration and login
✅ Password hashing with bcrypt
✅ Secure sessions
✅ Create and manage trips
✅ Traveller posts and comments
✅ Company accounts for trip providers
✅ Responsive UI

## Tech Stack

Frontend:

- HTML
- CSS
- JavaScript

Backend:

- Node.js
- Express.js

- MySQL
- bcrypt
- express-session

## Installation

Clone the repository:

git clone https://github.com/NKC27/solo-traveller-main

Install dependencies:

npm install

Create a .env file:

DB_NAME=your_database
DB_USER=your_username
DB_PASSWORD=your_password

Start application:

npm start

Application runs at:

http://localhost:3001
